Petunjuk Penggunaan Media

Panduan langkah demi langkah untuk siswa dan guru

Untuk Siswa

  1. Isi Nama Lengkap dan pilih Kelas di halaman Beranda.
  2. Pelajari 8 kartu interaktif di menu Materi secara berurutan.
  3. Coba petualangan visual di menu Eksplorasi Ekosistem.
  4. Mainkan 3 mini game edukatif di menu Game untuk melatih keterampilanmu.
  5. Kerjakan Latihan Soal untuk mempersiapkan diri sebelum Kuis.
  6. Selesaikan Kuis Akhir (15 Soal) untuk mendapatkan Nilai dan Rekomendasi Belajar!

Untuk Guru

  • Gunakan media ini sebagai alat bantu mengajar interaktif di kelas maupun tugas mandiri.
  • Akses Halaman Guru untuk memantau rekap nilai seluruh siswa secara realtime.
  • Hubungkan media dengan Google Apps Script agar hasil kuis otomatis tersimpan ke Google Sheets.
  • Gunakan fitur Cetak / Ekspor untuk mengunduh rekap hasil belajar siswa.
